# Credits

Fonts are served locally so the dashboard does not contact a third-party font service.

## Material Symbols Outlined

`material-symbols-outlined.woff2` is the weight-400 outlined font from
[`@material-symbols/font-400` version 0.48.0](https://www.npmjs.com/package/@material-symbols/font-400),
based on [Google Material Symbols](https://github.com/google/material-design-icons).

The Apache 2.0 license is included in the [font license](localghost/frontend/static/fonts/LICENSE).

## Inter

`inter-latin-variable.woff2` is vendored from `@fontsource-variable/inter` version 5.3.0.

The SIL Open Font License is included in [Inter-OFL.txt](localghost/frontend/static/fonts/Inter-OFL.txt).
